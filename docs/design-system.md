# 设计系统（Design System）

> 唯一事实来源：`design/tokens.json`。执行 `pnpm tokens` 生成
> `admin/src/styles/tokens.css`（CSS 变量）与 `miniapp/src/styles/tokens.scss`（SCSS 变量，长度单位 ×2 → rpx）。
> 任何颜色、间距、圆角、字号、动效**不得**在业务代码里写硬编码值。

---

## 1. 设计主张

**墨、纸、金、朱砂。**

《燕云十六声》的底色是五代十国的苍凉：旧纸、残墨、铜锈、暗金、血朱。
本项目把它收敛成一套克制的界面语言：

- **纸为底**（`#F7F2E9`）：不用纯白，暖调宣纸衬托内容的"手作感"
- **墨为字**（`#1B1815`）：正文近黑的暖墨，不用纯黑，避免屏幕上的生硬
- **金为线**（`#B08A45`）：只用于 1px 分隔线、印章边框、重点描边——是"鎏金丝"，不是装饰
- **朱砂为点**（`#A6322A`）：全站唯一的高饱和强调色，只给"当前态 / 主操作 / 稀有度高光"
- **留白为韵**：古风的高级感来自留白。宁可少放一个元素，也不要填满

**克制原则**：不加渐变按钮、不加发光、不加多层投影、不加粒子。动效只做「位移 + 透明度」，不做旋转弹跳。

每个色系含 4 档（`600/500/400/100`），规则：**500 做主色，600 做文字/描边，100 做底色**。

## 3. 字体

| Token | 值 | 场景 |
|---|---|---|
| `font-display` | `"Songti SC", "STSong", "Source Han Serif SC", "Noto Serif SC", "SimSun", serif` | 大标题、数字、印章字 |
| `font-body` | `-apple-system, "PingFang SC", "Microsoft YaHei", ...` | 正文、表格、表单 |

- **衬线（宋/楷）承担"古"**：页面主标题、区块标题、时装名、价格、统计数字
- **无衬线承担"今"**：正文、表单、按钮、表格
- 小程序不支持远程字体，全部走系统字体族降级，**禁止** `@font-face` 引外链

字号阶梯（`--text-*`）：`12 / 13 / 14 / 16 / 18 / 20 / 24 / 30 / 38`（小程序 ×2rpx）

字重只用 `400 / 500 / 700`；标题靠**字号与字距**拉开层次，不靠加粗。

字距：中文标题 `0.04em`；小标签全大写式弥散 `0.12em`；正文 `0`。

## 4. 间距 / 圆角 / 阴影

**间距**以 4 为基：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72`。
布局节奏：卡片内边距 `16~20`，卡片间距 `12`，区块间距 `32`，区块标题下间距 `16`。

**圆角**：`2 / 4 / 8 / 12 / 16 / 24 / 999`

| 元素 | 圆角 |
|---|---|
| 标签 chip | `4` |
| 图片 / 卡片 | `12` |
| 弹窗 / 抽屉 | `16` |
| 头像、圆形按钮 | `999` |

古风审美偏"方中带圆"，**不给大圆角胶囊按钮**（除 tab / 头像）。

**阴影**：只三级，全部低透明度、大扩散，模拟纸面浮起。

```
--shadow-sm: 0 2px 8px -2px rgba(27,24,21,.08)
--shadow-md: 0 6px 20px -8px rgba(27,24,21,.16)
--shadow-lg: 0 16px 44px -16px rgba(27,24,21,.22)
--shadow-ink: 0 24px 60px -24px rgba(16,14,12,.45)   // 深色浮层
```

## 5. 动效

| Token | 值 | 用途 |
|---|---|---|
| `motion-fast` | `140ms` | hover、按下、图标切换 |
| `motion-base` | `220ms` | 常规过渡、展开收起 |
| `motion-slow` | `380ms` | 抽屉、页面进入 |
| `motion-ease` | `cubic-bezier(.22,1,.36,1)` | **默认**，出场快、收尾柔 |
| `motion-spring` | `cubic-bezier(.34,1.56,.64,1)` | 仅用于收藏心形等情感化反馈 |

**只允许**：`opacity`、`transform`、`height`（少量）。
**禁止**：`width` 动画、旋转、弹跳、无限循环动画（加载态除外）。

进场：`opacity 0→1` + `translateY(8px)→0`，`motion-base`，卡片列表按 index 递增 `40ms` 延迟（最多 8 个）。

## 6. 图标

| 端 | 方案 | 理由 |
|---|---|---|
| 后台 | `lucide-vue-next` | 与 Lucide React 同一套几何语言（1.5px 描边、24 网格），Vue 官方移植 |
| 小程序 | `uni-icons`（uni-ui 自带） | 小程序不支持内联 SVG；字体图标跨端稳定、体积小 |

规则：**图标只做功能指示，不做装饰**。尺寸 `14 / 16 / 20`，颜色跟文字色走（`currentColor`）。

## 7. 布局

### 7.1 后台（桌面优先，最低可用 1024px）

```
┌─────────┬──────────────────────────────────────┐
│ 侧边栏   │ 顶栏：面包屑 · 搜索 · 用户            │
│ 216px   ├──────────────────────────────────────┤
│ 墨色     │ 页签条（可关闭，横滚）                 │
│ 可折叠64 ├──────────────────────────────────────┤
│         │ 内容区：纸色底 + 白卡片 + 16~24 间距    │
└─────────┴──────────────────────────────────────┘
```

- 侧边栏：`ink-900` 底，未选中 `ink-300` 文字，选中 = `paper-50` 文字 + 左侧 2px 朱砂竖条 + `rgba(255,255,255,.06)` 底
- 内容区最大宽 `1280`，居中
- `< 1200px` 侧边栏自动折叠为图标条；`< 900px` 抽屉式

### 7.2 小程序（750 设计稿，rpx）

- 页面左右安全边距 `32rpx`
- 双列瀑布网格：卡片宽 `(750-32*2-24)/2 ≈ 331rpx`，间隙 `24rpx`
- 底部 tabBar 高度 `112rpx` + 安全区
- 顶部导航用自定义（沉浸式）：`sy` 状态栏高度 + `88rpx`
- 所有列表必须实现：**加载骨架 / 空状态 / 错误重试 / 下拉刷新 / 触底加载**

## 8. 组件规范（两端对照）

| 能力 | 后台 | 小程序 |
|---|---|---|
| 按钮 | `a-button`（改主色 / 圆角 8） | 自定义 `InkButton`（3 变体：primary / ghost / text） |
| 卡片 | `a-card` 轻改 | `InkCard`（白底 + 1px 边框 + 12 圆角 + sm 阴影） |
| 标签 | `a-tag` | `RarityTag` / `ChipGroup` |
| 空态 | 自定义 `EmptyState` | `EmptyState`（宣纸纹理 + 一行字 + 一个操作） |
| 加载 | `a-skeleton` | `SkeletonCard`（shimmer 扫光，仅此处允许循环动画） |
| 反馈 | `message` / `Modal.confirm` | `uni.showToast` / `uni.showModal` |
| 浮层 | `a-drawer` / `a-modal` | `uni-popup` |

统一要求：
- **每个可点元素必须有反馈**（hover / active / loading / disabled）
- **每个异步区块必须有四态**（loading / empty / error / success）
- 表单校验错误就近显示，不弹 toast

---

## 9. 装饰元素的边界

允许：
- 1px 金线分隔（`--gold`，30% 透明度）
- 印章式方形小标（朱砂底 + 白字，`2px` 圆角）
- 中文竖排小字（≤ 4 字，`tracking-widest`）
- 极低透明度（≤4%）回纹／云纹 CSS 背景

禁止：
- 龙凤祥云大图、卷轴边框、毛笔飞白、发光文字
- 任何形式的水印、渐变遮罩滥用
- 超过 2 种装饰元素出现在同一屏
